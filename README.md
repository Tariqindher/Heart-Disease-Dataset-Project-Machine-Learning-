# ❤️ Heart Disease Machine Learning Project

## 📌 Overview

This project analyzes the **Heart Disease UCI dataset (heart_disease_uci.csv)** using Machine Learning techniques such as preprocessing, dimensionality reduction, clustering, and classification to predict heart disease effectively.

---

## ⚙️ Technologies Used

 * 🐍 Python
 * 📊 Pandas & NumPy
 * 📈 Matplotlib
 * 🤖 Scikit-learn

---

## 📂 Dataset

The dataset contains medical attributes like age, cholesterol, blood pressure, and heart rate used to predict the presence of heart disease.

---

## 🔄 Project Workflow

📥 Data Loading → 
🧹 Cleaning → 
🔤 Encoding → 
⚖️ Scaling → 
📉 PCA (95% variance) → 
🔍 K-Means Clustering → 
🌳 Random Forest → 
⚡ SVM → 
📊 Evaluation

---

## 🧠 Machine Learning Techniques

* 📉 **PCA**: Reduces dimensions while preserving important information
* 🔍 **K-Means**: Identifies hidden patterns/clusters in data
* 🌳 **Random Forest**: Improves prediction using multiple decision trees
* ⚡ **SVM**: Classifies data using optimal decision boundaries

---

## 📊 Visualizations

* 🔥 Correlation Heatmap
* 📉 Elbow Method Plot
* 📌 Scatter Plot
* 📊 Confusion Matrix

---

## ✅ Results

✔️ PCA reduced unnecessary features
✔️ K-Means discovered meaningful clusters
✔️ Random Forest & SVM achieved strong classification performance
✔️ Evaluation done using accuracy & confusion matrix
